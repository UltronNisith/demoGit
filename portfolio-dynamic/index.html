    How to update this page

    Everything on this page comes from one file: portfolio-dynamic/data.json in this repo (branch dynamic-portfolio).

    New certificate: copy a block inside "certifications", change the name/dates, and paste your Credly badge image URL into "badgeImage" — the real badge picture will appear automatically. Leave it empty and a clean text badge is shown instead.

    New study goal: copy a block inside "currentlyPreparing" — set the title, provider, target date and progress (0–100). Commit the file and the page updates itself. No HTML editing, ever.
