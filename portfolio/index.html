How the Language App gets hosted — free

Static apps like this one need no server or database, so hosting is free with HTTPS included. This is the exact path for a CV-ready public link.

  1. GitHub account — done ✓Username @UltronNisith — one account holds both the code and the live site, so recruiters see both in one place. Pages already works on my demoGit repo: ultronnisith.github.io/demoGit.
  2. Create the user-site repo + push the appCreate a repo named UltronNisith.github.io, put this portfolio at its root and the Language App in a language-app folder, with a README and screenshots.
  3. Turn on GitHub PagesSettings → Pages → deploy from branch. The portfolio will be ultronnisith.github.io and the Language App ultronnisith.github.io/language-app. Faster alternative: add just the language-app folder to the existing demoGit repo for ultronnisith.github.io/demoGit/language-app.
  4. Paste the live link into CV & LinkedInLive demo first, code second — that's the order hiring managers click.
GitHub Pages — recommended ✓

Free, always on, free HTTPS. Code + live site together. Best for a CV.

Cloudflare Pages

Unlimited bandwidth, very fast. Good if an app gets lots of visitors.

Netlify

Easiest drag-and-drop deploy. Free tier is tighter (credits/month).

Vercel / Render

Vercel for React / Next.js later. Render only when an app needs a real backend.
